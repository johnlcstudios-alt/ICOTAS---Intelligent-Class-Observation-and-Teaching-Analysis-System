# ICOTAS Documentation

This folder is part of the application source but is denied to web requests by `.htaccess`. Read it from the repository or deployment workstation, not from the public site.

## Reading order

1. **`architecture.md`** — how a request flows through the application and where responsibilities live.
2. **`database.md`** — the 43-table schema, key relationships, and demo/live scoping.
3. **`rbac.md`** — who may do what, and where authorization is enforced.
4. **`anonymity.md`** — how responses are separated from student identity and what remains risky.
5. **`qr-lifecycle.md`** — token generation, states, display, revocation, and print.
6. **`ai-and-prediction.md`** — exact labeling, algorithms, thresholds, and limitations.
7. **`uat.md`** — ISO/IEC 25010 process, fixed interpretation thresholds, and current results.
8. **`security.md`** — controls, secrets, headers, and operational hardening.
9. **`demo-data.md`** — fictional dataset, accounts, isolation, and reset.
10. **`testing.md`** — commands, environments, evidence, and untested scope.
11. **`deployment-infinityfree.md`** — deployment package, hosting steps, manual fallback, and smoke checklist.
12. **`research-alignment.md`** — claim boundaries and mapping to the research brief.

## Claim policy

Documentation uses four labels consistently:

| Label | Meaning |
|---|---|
| **Existing reported research value** | A number or conclusion attributed to the original study. Not reproduced here unless verifiable. |
| **New implementation result** | A result produced by this codebase and its tests during this build. |
| **Synthetic demonstration data** | Fictional records generated by `DemoService`, flagged `is_demo`, and resettable. Never research evidence. |
| **Unvalidated estimate** | Rule-based prediction output. Not a validated ML accuracy claim. |

The research manuscript was not present in the repository. Any manuscript-specific value that is not quoted in the project brief is marked as requiring reconciliation rather than guessed.

Local validation is complete against XAMPP (Apache 2.4.58, PHP 8.0.30, MariaDB 10.4.32). InfinityFree deployment is **not yet tested**; the guide defines the procedure and the evidence that must be collected before compatibility is claimed.
